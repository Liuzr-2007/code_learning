# ♟ 黑白棋 · b_and_w

一个用 **Python** 编写的命令行黑白棋（Reversi / Othello）小游戏。你执**黑棋**，AI 执**白棋**，基于 **MCTS（蒙特卡洛树搜索）** 与你对弈。

> 本项目为纯控制台程序，无图形界面，跨平台可运行（Windows / macOS / Linux）。

---

## ✨ 功能特性

- ✅ 完整实现黑白棋标准规则：8×8 棋盘、夹取翻转、无子可下自动跳过、终局胜负判定
- 🤖 基于 **MCTS + UCT** 的 AI 对手，思考策略优于纯随机
- 💻 简洁的字符界面，带清屏刷新，体验流畅
- 📦 可一键打包为 Windows 独立 `.exe`，无需安装 Python 即可运行

---

## 🚀 运行方式

### 方式一：直接运行源码（需要 Python）

1. 安装 **Python 3.8+**（下载地址：https://www.python.org/downloads/）
2. 安装依赖：

   ```bash
   pip install numpy
   ```

3. 运行游戏：

   ```bash
   python b_and_w.py
   ```

### 方式二：打包成 Windows exe（无需 Python）

在 Windows 上双击 `打包成exe.bat` 即可自动生成 `dist\b_and_w.exe`，之后双击 exe 就能玩，也可拷贝到其他 Windows 电脑使用。详见下文「打包说明」。

## 🎮 玩法与操作

- 坐标格式为 **`行 + 列`**，如输入 `3E` 表示第 3 行、E 列。
- 行取值范围 **0~7**，列取值范围 **A~H**。
- 你和 AI 轮流落子；落子后需**夹住**对方棋子（该行/列/对角线上，中间是对方棋子、两端是自己的棋子）才能翻转它们。
- 若某方无合法落子点则自动**跳过**该回合；双方都无子可下时游戏结束。
- 终局统计双方棋子数，**棋子多者获胜**。

### 合法落子示例

棋盘上初始四子位于棋盘中央（3D、3E、4D、4E 交错）。黑棋第一步可下在能翻转白棋的位置（如 `2E`），合法后才能落子，否则会提示重输。

## 📖 游戏规则（黑白棋标准规则）

- 棋盘为 8×8，共 64 格。
- 开局时中央四子交错放置：`(3,3)` 黑、`(3,4)` 白、`(4,3)` 白、`(4,4)` 黑。
- 落子必须落在**空位**，且能在水平、垂直或对角线方向上**夹住**至少一颗对方棋子。
- 夹住的对方棋子全部翻转为自己的颜色。
- 无合法落子点时跳过回合；双方均无法落子时游戏结束。

## 🧠 AI 设计：MCTS 蒙特卡洛树搜索

AI 采用 **MCTS（Monte Carlo Tree Search）+ UCT 公式** 决策：

1. **选择（Selection）**：从根节点出发，按 UCT 值选择最优子节点，直到叶子节点。
2. **扩展（Expansion）**：为当前局面随机选择一个合法落子点，生成子节点。
3. **模拟（Rollout）**：从新节点开始随机对弈到终局，得到胜负结果。
4. **回传（Backpropagation）**：将结果沿路径回传，更新各节点胜率与访问次数。

AI 每步默认模拟 **300 次**（源码中 `mcts(Node(board, WHITE), 300)` 可调）。模拟次数越多，AI 越强，但思考时间也越长。

> 当前 Rollout 采用纯随机策略，仍有提升空间（如加入启发式评估），欢迎扩展。

## 📦 打包说明（生成 Windows exe）

### 一键打包（推荐）

1. 安装 Python 3.8+，安装时**务必勾选 "Add Python to PATH"**。
2. 双击运行 `打包成exe.bat`。
3. 脚本会自动安装依赖并打包，完成后 exe 位于 **`dist\b_and_w.exe`**。

### 手动打包（等价命令）

```bash
python -m pip install numpy pyinstaller
python -m PyInstaller --noconfirm --clean b_and_w.spec
```

## 🔧 依赖清单

- `numpy`：棋盘数据用 numpy 二维数组表示
- `pyinstaller`：打包 exe 用（仅打包时需要）

## 📝 说明与已知限制

- 生成的是**控制台程序**，需在命令行/终端中运行，无图形界面。
- AI 采用随机模拟，强度中等；增大模拟次数可提升棋力，但会变慢。
- 若在 ARM 架构 Windows（如部分骁龙笔记本）上打包，请在对应设备上重新执行打包命令。
