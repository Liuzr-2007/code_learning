桌面宠物  使用说明
====================

【运行环境】
- Windows 系统
- Python 3(自带 tkinter)
- Pillow 库：  pip install pillow

【启动方式】
- 双击  启动宠物.vbs   （推荐，无控制台窗口）
- 或双击 启动宠物.bat
- 或命令行：  pythonw pet.py

【文件说明】
- pet.py            主程序
- sprite.png        精灵图素材(含全部动作小人，请勿改名/替换格式)
- 启动宠物.vbs      无窗口启动器
- 启动宠物.bat      批处理启动器
- README.txt        本说明

【操作】
- 左键拖拽：抓起宠物移动；松手受重力落到下方窗口上沿或地面，落地有小弹跳
- 双击：立刻换一个随机动作
- 右键菜单：🍖喂食 / 🎲换个动作 / 💤休息 / 💬说句话 / ℹ️关于 / ❌退出
- 把宠物拖到窗口顶部上方松手，可落到该窗口上沿；行走时走到窗口边缘会自然掉落
- 每 30 秒~2 分钟随机切换动作；row1=向右走、row2=向左走，启动默认播放 row3

【退出】
- 右键 → ❌退出  (无控制台窗口，请用菜单退出)

【可调参数】(pet.py 顶部)
- PET_HEIGHT        宠物显示高度
- WALK_SPEED        走动速度
- ACTION_SWITCH_MIN/MAX  动作切换间隔(秒)
- ACTIONS / RANDOM_POOL  动作与行号映射、随机池
- ENHANCE / SHARPEN_*    清晰度增强与锐化参数
